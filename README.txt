# Portal Centro Educa Mais Dom Ungarelli

## Como abrir no VS Code
1. Extraia a pasta `dom-ungarelli-site`.
2. Abra a pasta no Visual Studio Code.
3. Abra `index.html` no navegador ou use a extensão Live Server.
4. As imagens estão na pasta `img`.

## Área do Aluno
A versão demonstrativa permite cadastrar notícias, eventos e projetos. Os dados ficam salvos no navegador com localStorage.
Para uso real por vários alunos e professores, substitua o localStorage por um banco de dados/backend com login e aprovação de conteúdo.
